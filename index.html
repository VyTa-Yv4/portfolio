01Internship · 2026La Rose Noire PH

FAC-ITMS

Facilities item & uniform request system

Replaced paper request handling for La Rose Noire's facilities team. Employees request chemicals, materials, uniforms and PPE through a digital copy of the official uniform request form. Every request moves through one tracked lifecycle.

  • Request → approve/reject → issue → return → receipt, with an audit log of every edit
  • Role-based access for employees, managers, the uniform custodian and admins
  • Storage and stock monitoring, weekly usage reports, data export and in-app chat
  • PHP
  • MySQL
  • JavaScript
  • Tailwind CSS

02Thesis · 2025–26Team of 4

OAMS

Online Assessment Monitoring System

A decision-support tool for online exams. It combines phone detection with head-pose and gaze tracking and flags suspicious behavior for a human proctor to review.

  • Faster R-CNN detects smartphones; MediaPipe Face Mesh with solvePnP estimates yaw, pitch and roll
  • Per-examinee calibration and sliding-window analysis tell brief glances apart from repeated behavior
  • Low / Moderate / High risk levels, evidence frames, and a Firebase-backed dashboard for the professor
  • Python
  • PyTorch
  • MediaPipe
  • OpenCV
  • Firebase
  • React
  • Docker
